# SU3HOB-ladder

[![DOI](https://zenodo.org/badge/1350014789.svg)](https://doi.org/10.5281/zenodo.22150397)

Harmonic-oscillator (Talmi–Moshinsky) transformation brackets in the SU(3)
basis, with the SU(3) ⊃ SO(3) isofactors generated from the U(2) pseudo-spin
ladder operators.

Fortran 2008, self-contained, MIT licensed.
No SU(3) coupling library is required at any point.

## What it computes

The general Talmi–Moshinsky bracket

```
<e1 l1, e2 l2 : L | T(d) | e1' l1', e2' l2' : L>
```

for an arbitrary mass-ratio parameter `d`, via the SU(3)-basis expression of

> R. K. Kalinauskas, A. Stepšys, D. Germanas, S. Mickevičius,
> *Calculation of harmonic oscillator brackets in SU(3) basis*,
> Nucl. Phys. A **1056** (2025) 123033; [arXiv:2501.19131](https://arxiv.org/abs/2501.19131).

The bracket reduces to one sum over Wigner *d*-functions of the
reflection-containing Talmi–Moshinsky matrix, weighted by products of
SU(3) ⊃ SO(3) isofactors of the chain U(6) ⊃ U(3) × U(2).

## How the isofactors are obtained

This is what distinguishes the package: they come from no coupling library at
all. The U(2) factor of the chain is generated by the pseudo-spin bilinears

```
J+ = a+(1).a(2),    J- = J+^T,    Jz = (N1 - N2)/2
```

`J+` is an SO(3) scalar, so it acts within fixed `(E,L)` and raises
`M = (e1-e2)/2` by one. Because the U(3) and U(2) labels inside `[E]` of U(6)
are complementary, classifying this pseudo-spin at fixed `(E,L)` **is** the
SU(3) ⊃ SO(3) classification. Hence

| | |
|---|---|
| highest weights | `ker J+` in the block `M = J` |
| the rest | obtained by lowering with `J-` |

The kernel comes from the Gram matrix `G = J-J+ = J^2 - M(M+1)`, whose exact
eigenvalues are `J'(J'+1) - M(M+1)`, so the rank decision is never marginal.
Lowering — rather than solving each `M` separately — is what fixes **one**
consistent multiplicity label `alpha` across the whole tower.

Consequences: the isofactors are orthonormal by construction; there is no
K-matrix, no inverse square root of an overlap matrix, and no outer
multiplicity to resolve.

The full derivation is given in the [accompanying article](#accompanying-article),
which sets out the construction step by step.

## Build and test

```sh
make            # builds test_hob_su3 and hob
make check      # runs the validation driver, compares with the reference
make bench      # builds the timing / accuracy driver in bench/
make clean
```

Only a Fortran 2008 compiler is required for the library and the CLI.
BLAS/LAPACK is needed for `bench/` only (`dsyev` and `matmul`).

To use a compiler other than `gfortran`:

```sh
make FC=ifx
```

## Public interface

Module `hob_su3`:

```fortran
call hob_init(Emax)                        ! once, before anything else
call hob_build_basis(E, L, b)              ! coupled basis of the block
call hob_prepare(E, L, S)                  ! d-INDEPENDENT isofactor towers
call hob_eval(S, d, H)                     ! whole HOB matrix for this d
val = hob_bracket(S, e1,l1,e2,l2, e1p,l1p,e2p,l2p, d)
i   = hob_state_index(b, e1, l1, l2)
a0  = alpha_mult(E, twoJ, L)               ! Racah inner multiplicity
```

The design point: `hob_prepare` does not depend on `d`. Prepare a block once,
then evaluate it for as many mass ratios as wanted — *prepare once, evaluate
many*:

```fortran
call hob_prepare(E, L, S)                  ! once per block
do i = 1, nd
   call hob_eval(S, d(i), H)               ! any number of mass ratios
end do
```

There is also a command-line front end:

```sh
./hob E L d                                    # a whole block
./hob e1 l1 e2 l2 e1' l1' e2' l2' L d          # a single bracket
```

## Validation

`test_hob_su3` checks, for every `(E,L)` up to `Emax` and several `d`:

1. `alpha_0` against the Racah inner-multiplicity formula, per tower;
2. orthonormality, `max |HOB.HOB^T - I|`;
3. the involution property, `max |HOB^2 - I|`;
4. element-by-element agreement with the classical Talmi–Moshinsky formula of
   Kamuntavičius et al. (2001), evaluated independently by `tmb_kam.f90`;
5. the S(3) relations carried by the `d = 1/3` brackets, where
   `P23 = HOB(1/3)` and `P12 = diag((-1)^l1)`:
   `P23^2 = I` and `(P12 P23)^3 = I`.

Test 2 is necessary but **not** sufficient: it vanishes identically under a
spurious orthogonal rotation of a block, so it bounds only the non-orthogonal
part of the error. Tests 4 and 5 are the ones that close that gap.

## Benchmarks

```sh
./bench/ladder Emax
```

prints per-shell prepare / evaluate times and `max |HOB.HOB^T - I|`.
Representative single-core figures (`gfortran -O2`):

| E | prepare | evaluate | `max｜HOB.HOB^T - I｜` |
|---:|---:|---:|---:|
| 30 | 0.16 s | 0.14 s | 1.5 × 10⁻¹⁰ |
| 50 | 5.9 s | 7.1 s | 1.8 × 10⁻⁶ |

The whole `E <= 50` range is reachable; accuracy degrades smoothly.

## Accompanying article

> A. Stepšys, S. Mickevičius, D. Germanas,
> *SU3HOB: a Fortran package for harmonic-oscillator brackets in the SU(3)
> basis from pseudo-spin ladder operators*.

It describes the method, compares it against two independent routes to the
same brackets, and applies it to three-particle coefficients of fractional
parentage. The article is not part of this source tree.

`make bench` reproduces the ladder timings and orthonormality quoted there.
The measurement logs from the runs behind every table are in `logs/`, and
[MANIFEST](MANIFEST) says which log backs which table.

## Files

| file | contents |
|---|---|
| `hob_su3.f90` | the method: coupled basis, `J+` construction, kernel + lowering, Wigner *d*-functions, bracket assembly |
| `WignerSymbol.f90` | SU(2) Clebsch–Gordan coefficients, used to build the `J+` matrix elements. Bundled unmodified from [WignerSymbol](https://github.com/0382/WignerSymbol), Copyright (c) 2022 0382, MIT License |
| `tmb_kam.f90` | the classical Talmi–Moshinsky bracket (see below). Used only by the validation driver; the library itself does not depend on it |
| `hob.f90` | command-line front end |
| `test_hob_su3.f90` | validation driver; `test_hob_su3.ref` is its stored reference output |
| `bench/` | timing and accuracy driver |
| `logs/` | measurement logs behind the tables of the article |

`tmb_kam.f90` implements the compact expression of Kamuntavičius et al.,
Nucl. Phys. A **695** (2001) 191, Eq. (26). The 6*j* (Sec. 9.2.1), 9*j*
(Sec. 10.2.4) and Clebsch–Gordan (Secs. 8.2.1, 8.5.1) coefficients are those
of Varshalovich, Moskalev and Khersonskii. Factorials and double factorials
are tabulated in logarithms rather than as binomial and trinomial tables,
which is what carries the expression past `E ~ 12` to `E = 50`.
